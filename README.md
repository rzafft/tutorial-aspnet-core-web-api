# REST API with ASP.NET Core Tutorial

A REST API (Representational State Transfer Application Programming Interface) is software that allows applications to communicate with one another over HTTP. Instead of directly connecting to a database, applications send HTTP requests to an API. The API validates the request, performs business logic, communicates with the database, and returns a response.

In modern software development, APIs separate the frontend from the backend. This allows multiple applications—such as websites, mobile apps, desktop applications, or other services—to use the same backend without duplicating code.

For example, later in this series:

- React website → calls the API
- .NET MAUI mobile app → calls the same API
- Future Python scripts → could also call the API

None of these applications will communicate directly with SQL Server. Instead, every request flows through the API.

### What is ASP.NET Core Web API?

ASP.NET Core is Microsoft's modern framework for building web applications and backend services. One project type inside ASP.NET Core is called 'Web API'. A Web API project exposes endpoints that clients can call using HTTP.

### The goal of this tutorial

In the previous tutorial we built a SQL Server database that stores university admissions information. Our goal is to create an API that allows other applications to access this information safely.

By the end of this tutorial we'll have an API capable of

```
GET     /api/students
GET     /api/students/15
POST    /api/students
PUT     /api/students/15
DELETE  /api/students/15
```

These are called CRUD operations.

# Step 1: Create an ASP.NEt Core Web API Project

Now that we have a SQL Server database, we need to build an application that can communicate with it. Rather than allowing websites or mobile applications to connect directly to the database, we will create a REST API. This API will receive HTTP requests, perform any necessary business logic, retrieve or modify data in SQL Server, and return responses to the client.

The first step is to create an ASP.NET Core Web API project. A project is a collection of source code, configuration files, and dependencies that together define an application. Microsoft provides project templates that generate a basic application structure, allowing developers to focus on building features instead of creating everything from scratch.

In this tutorial we will use the ASP.NET Core Web API project template. This template creates a minimal but fully functional REST API with routing, dependency injection, configuration files, and an embedded web server already configured.

Inside `tutorial-aspnet-core-web-api` run the following command: `dotnet new webapi`

* `dotnet` launches the .NET command-line interface (CLI).
* `new` tells the CLI to create a new project.
* `webapi` specifies that we want to create an ASP.NET Core Web API project using Microsoft's built-in template.
